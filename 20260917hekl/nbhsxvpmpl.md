# 人工授精前需要做哪些检查？

> 更新时间：2026-09-17 (UTC+8)

**人工授精（AI）**是通过非性交方法将精子置于女性生殖道内，以期精卵自然结合，达到妊娠目的的而采用的一种辅助生育技术。

我们现在最常见的就是**宫腔内人工授精（IUI）**，是将处理过的精子悬液通过导管直接注入宫腔内。常配合促排卵，适应证广泛，如少、弱、畸形精子症，精液不液化症，免疫性不孕症，宫颈因素不孕，原因不明不孕症等。

**人工授精前女方至少要有一输卵管通畅**
由于人工授精只是将精子输送到宫腔，所以女方至少要有一侧输卵管是通畅的，这样的话精子和卵子才能见面完成受精的过程。因此在进行人工授精前需要进行输卵管通畅情况的检查，比如输卵管造影。
如果输卵管造影显示出输卵管通畅，就可以进行人工授精前的常规化验了。

**人工授精前女方进行常规检查**
1.血液检查包括：血型/RH型，HIV抗体，梅毒血清学抗体检测，乙肝两对半，丙肝抗体，肝肾功能，血常规，TORCH
2.阴道分泌物检查：白带常规，支原体、衣原体、淋球菌培养，宫颈细胞学检查
3.尿常规
**人工授精前男方要完成以下检查**
1.血液检查包括：血型/RH型，HIV抗体，梅毒血清学抗体检测，乙肝两对半，丙肝抗体

2.精液常规检查报告至少2张，精浆生化，抗精子抗体等
3.支原体、衣原体、淋球菌培养

以上的化验在进行检查时一定要注意化验单上的名字必须与身份证上的名字相同，对使用同音字，小名的化验单我们是不承认的，需要重新更名后化验。
以上检查大多是有时间的要求的，均为1年有效期，完成化验后应尽早治疗。

除了以上化验，进行人工授精治疗的不孕夫妇还需要准备一些证件，包括双方的身份证件，结婚证，准生证或生育状况证明。结婚证或准生证/生育状况证明上的名字，身份证信息必须一致，否则不被承认。准生证/生育状况证明必须由专门的计生部门出具，有公章和电话，以备签字前核对。
