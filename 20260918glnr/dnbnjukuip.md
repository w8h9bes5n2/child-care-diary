# 钧钧妈分享：不管宅在家还是外出玩，都得预防“登革热”

> 更新时间：2026-09-18 (UTC+8)

炎炎夏日，陪伴我们的除了空调，还有带来3D立体环绕“嗡嗡嗡”声的蚊子。大家可别小看精力爆表的它们，如果被叮咬可能会染上可怕的疾病，比如登革热。

警惕登革热侵袭

登革热疫情通常流行于东南亚、非洲、南美国家，但这段时间江苏、广州、安徽等多地发出警惕登革热的提醒。希望大家无论是在家还是外出游玩都要注意防蚊灭蚊，被蚊虫叮咬后也不要大意!

这是一种由登革热病毒(DENV)引起的急性传染病，6月—11月多发，一般会在感染后的5—8天内发病。患者常会出现突发高热、全身疼痛、皮疹等症状，具体可参考以下内容：

哪些人群是高危人群?

宝宝、孕妇、老人感染登革热的风险较高，另外肥胖或严重营养不良者，以及伴有糖尿病、高血压、肝硬化等基础病患者也容易感染此病毒。这些人群即便只出现轻微症状，也建议立即就医。

为何蚊子会传播登革热?

大家只知道虽说感染者是主要的传染源，但人与人之间通常并不传播。该病毒主要由伊蚊(花斑蚊)传播，也就是常说的花蚊子叮咬传播。也就是说伊蚊是登革热传播的唯一媒介。

除了登革热，伊蚊还能传播Zika病毒、黄热病、基孔肯雅热等。另外，蚊子还能传播流行性乙型脑炎(发烧、剧烈头痛等)、丝虫病、疟疾(间接性发冷、发热等)等。

预防登革热

从源头抓防控是关键。灭蚊+避免蚊子叮咬是最实用、最简单的防护行为。大家可要积极行动起来!

★ 家中防蚊

1. 清除花盆、地漏、空调、垃圾桶等处积水，防止蚊子滋生。

2. 设置物理屏障，安装纱窗、纱门等，阻止蚊虫进入。还可以在纱窗上喷洒杀虫剂，增强防护效果。

3. 使用蚊帐，或驱蚊产品等。比如将驱蚊剂喷在手臂、腿等裸露部位。Ps：我国生产的合格驱蚊产品可安全用于2个月的婴幼儿。

4. 杀虫气雾剂用起来。注意先收好餐具，不要向床单、衣物上直接喷洒，喷洒后还应关好门窗，等开窗通风1h散尽后再进入房间。

★ 外出旅游也要多注意

进入疫区时，防护更要做好。

1. 租住卫生条件好、蚊虫少的酒店或宾馆。

2. 穿长袖长裤，减少暴露。这可比驱蚊制剂要有用的多。

3. 可在裸露皮肤处喷洒驱蚊剂，如果有条件可穿戴用菊酯类杀虫剂浸泡过的衣物，效果更好。

4. 尽量避免在树荫、草丛、凉亭等户外阴暗处逗留，远离有积水的地方。

5. 花蚊子出没的高峰时段(上午8—9时，傍晚4—6点)最好少出门溜达，如要外出注重防护。

这里也提醒大家，如果在登革热疫区流行结束15天内，出现发热、皮疹、关节疼痛等症状，建议尽早就医诊治，并向医生说明旅行史、蚊虫叮咬史。

目前，尚未有针对登革热病毒的特效药，一般采取对症支持治疗等措施。大家也不要太担心，只要按照上述方法，做好防蚊、灭蚊的工作，便能有效防护远离登革热，当然也能避免被蚊子叮得满身包啦~
