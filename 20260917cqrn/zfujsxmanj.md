# 【医院动态】“宁德市单髁学术论坛”在东侨院区举办

> 更新时间：2026-09-17 (UTC+8)

//  

9月17至18日，由我院关节与运动医学科主办的“宁德市膝关节单髁置换学术论坛”东侨院区举办。来自省内各地市的近50位骨科同道参会。会议由我院副院长、骨科学科带头人王小勇教授主持。

学术活动邀请到国内著名关节外科大师、上海杨浦医院涂意辉教授为大家讲授“单髁手术适应症及禁忌症”、“内侧单髁手术技巧”等课题，并做精彩手术演示；来自泉州正骨医院的徐福东教授分享了“单髁术后并发症”。省内各地市的多位专家及我院关节与运动医学科副主任医师黄家谷、柯铭锋作了精彩的病例分享。与会专家对相关病例进行充分交流，期间涂意辉教授也对病例进行深刻点评和分析。现场讨论气氛热烈、学术氛围浓厚。

根据学科发展和建设需要，院部统一规划部署、对骨科进行按亚专业分科。目前骨科分设关节与运动医学科、脊柱外科及创伤骨科三个专业、四个病区。此次学术论坛也是我院骨科按亚专科建设分科后开展的第一次学术活动，有助于提升我院关节外科的综合诊治水平和知名度，推动我院关节外科事业进步与发展。
